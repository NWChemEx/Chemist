Detailed Description

Models the basis set of one atom by value.

See AtomicBasisSetCommon for the shared API and for how the shells are stored. *this owns that state. See AtomicBasisSetView for a class with the same API which aliases state owned by something else.

The type of the shells is chosen when *this is constructed, from a ShellPurity and an AOOrdering, and is fixed thereafter: every shell added to *this has that type.

A default-constructed instance holds no shells, has an empty name and an atomic number of 0, is centered at the origin, and holds Cartesian shells in CCA order.

Note
A moved-from instance may only be assigned to, swapped, or destroyed.

The shell is centered on the center of *this, and has the type of the shells in *this.

Warning

[in]cbeginIterator to the beginning of the container holding the coefficients.
