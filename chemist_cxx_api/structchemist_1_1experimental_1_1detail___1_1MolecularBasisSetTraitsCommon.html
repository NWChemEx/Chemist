Detailed Description

Types shared by both ChemistClassTraits<MolecularBasisSet> specializations.

A molecular basis set stores one atomic basis set's worth of state per atom, back to back, so the parameter, shell, and per-atom types are pulled out of ChemistClassTraits<AtomicBasisSet> rather than being redeclared here.
