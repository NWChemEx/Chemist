Detailed Description

template<typename AOType>
class chemist::experimental::CCAShell< AOType >

Models a shell, in CCA order, by value.

See CCAShellCommon for the ordering and the shared API, and AOShell<AOType> for the interface *this satisfies as one of the orderings of a shell of that purity.

*this owns the one contracted Gaussian all of its AOs are built on, and with it the shell's center and angular momentum. Indexing *this hands out views, never copies. See CCAShellView for a class with the same API which aliases a contracted Gaussian owned by something else.

A default-constructed instance is an s shell built on a contraction with no primitives.

Template Parameters
AOTypeThe kind of AO *this holds. CCAShell<CartesianAO> is a Cartesian shell and CCAShell<SphericalAO> is a pure one.
