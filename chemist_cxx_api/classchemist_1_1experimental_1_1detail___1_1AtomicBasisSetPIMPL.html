Detailed Description

template<typename ShellType>
class chemist::experimental::detail_::AtomicBasisSetPIMPL< ShellType >

Implements an atomic basis set which owns its state.

This is what AtomicBasisSet holds. See AtomicBasisSetPIMPLBase for the layout of the state.

Template Parameters
ShellTypeThe type of the shells. Must not be const-qualified.

Implements add_shell.

The new state is built in full and then swapped in, so that a failure part way through (e.g. a floating-point type mismatch in the exponents after the coefficients went in fine) leaves *this untouched. This also makes it safe for coefficients and exponents to alias *this. Atomic basis sets are small, so the copy is cheap.
