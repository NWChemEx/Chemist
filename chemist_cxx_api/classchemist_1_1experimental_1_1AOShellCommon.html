Detailed Description

template<typename DerivedType>
class chemist::experimental::AOShellCommon< DerivedType >

Implements the API shared by AOShell and AOShellView.

Per docs/source/developer/design/basis_set/ao_hierarchy.rst, a shell is a set of AOs sharing one contracted Gaussian, a total angular momentum, and a purity, and the order in which it enumerates those AOs is part of its type: the classes deriving from AOShell (e.g. CCAShell) are the orderings. *this is the ordering-agnostic API those classes share, written once.

The purity decides what the shell holds: the Cartesian AOs built on the contracted Gaussian, or the spherical AOs built on the Cartesian shell of that contracted Gaussian.

Note what is NOT here: the angular index at an offset (the powers of a Cartesian shell, of a pure one). Which of the two a shell has depends on its purity, so it is provided by the concrete shells, which know their purity statically (e.g. CCAShell<CartesianAO>::cartesian_powers), rather than here, where asking the wrong one could only be a runtime error. Code holding an AOShell can still ask each AO it indexes about itself.

Exactly as AOCommon does for AO and AOView, *this implements each public method by calling a virtual hook on DerivedType (which is AOShell or AOShellView, not the concrete class). Methods which follow from other methods, e.g. size() from get_l() and is_pure(), are computed here rather than being hooks, so the derived classes can not disagree about them.

◆ at()

template<typename DerivedType >
const_ao_view_reference chemist::experimental::AOShellCommon< DerivedType >::at ( size_type  i) const
inline

Returns the AO at offset i.

Which kind of AO a shell holds is only known to its derived class, so the result is a polymorphic, read-only view: a CartesianAOView for a Cartesian shell and a SphericalAOView for a pure one. The view is owned by *this and aliases the state of *this; it is not a copy. Code which knows the concrete shell type can index it directly instead, and get a reference to the concrete view.

The returned reference is invalidated, much like a reference into a std::vector, by anything which changes the angular momentum of *this or rebinds its contracted Gaussian (assignment, swap, deserialization), and by the destruction of *this.
