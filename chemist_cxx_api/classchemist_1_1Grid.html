Detailed Description

Models an ordered list of GridPoint objects.

A grid is an ordered set of grid points, where each grid point has coordinates (presently described in Cartesian coordinates) and a weight.

Internally the weights of the grid points are stored in a tensorwrapper::Tensor of shape (N) and the coordinates of the grid points are stored in an experimental::PointSet. Since both type-erase their scalar type (via WeaklyTypedFloat), a Grid can hold values of any WTF-registered floating-point type.

Note
This class does not attempt to enforce the set-like nature of the grid (i.e., it will allow duplicate grid points).

This is the ctor that all other (non-default) ctors ultimately dispatch to; it is the only ctor whose implementation is not templated on the caller's iterator/range types.

Parameters

Template Parameters

EndItrThe type of the iterator pointing to just past the last grid point.

This ctor will create a new Grid by copying the grid points in the range [begin, end). It simply splits the range into a buffer of weights and a set of points and then dispatches to the (non-templated) weights/points ctor to do the actual work.

Parameters
[in,out]beginAn iterator pointing to the first grid point that should be in the Grid. If begin was passed by reference then after the call begin will compare equal to end
[in]endAn iterator pointing to just past the last grid point that should be included in the newly created grid.
Exceptions
std::bad_allocif there is a problem allocating the memory for *this. Strong throw guarantee.

◆ get_points()

Grid::point_set_reference chemist::Grid::get_points ( )

Returns the coordinates of every grid point, as a point set.

The returned view aliases the coordinates stored in *this; nothing is copied. Writing through the view returned by the mutable overload therefore moves the corresponding grid points of *this (their weights are unaffected). The const overload returns a read-only view.

Warning
The returned view is invalidated by anything which causes *this to reallocate its coordinates (e.g., assigning to *this).
Returns
A view of the points in *this.
Exceptions
std::bad_allocif constructing the view's state fails. Strong throw guarantee.
