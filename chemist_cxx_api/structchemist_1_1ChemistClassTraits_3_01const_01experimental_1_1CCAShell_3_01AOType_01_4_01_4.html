Detailed Description

template<typename AOType>
struct chemist::ChemistClassTraits< const experimental::CCAShell< AOType > >

Traits for a read-only experimental::CCAShell.

Identical to the mutable specialization except that every reference type has been const-qualified. This is what propagates const through CCAShellView, all the way down to the ContractedGaussianView it hands out.
