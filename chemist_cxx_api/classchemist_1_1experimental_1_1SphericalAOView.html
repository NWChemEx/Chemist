Detailed Description

template<typename SAOType>
class chemist::experimental::SphericalAOView< SAOType >

An object which behaves like a SphericalAO, but aliases the Cartesian shell it is built on.

*this is the spherical counterpart of CartesianAOView. Per docs/source/developer/design/basis_set/ao_hierarchy.rst, it is what a spherical shell will hand out when indexed: every spherical AO in such a shell is built on the one Cartesian shell it owns, and handing out views of it, rather than copies, is what keeps them from drifting.

The Cartesian shell is aliased through an AOShellView<CartesianAO>, so *this can alias a Cartesian shell of any ordering, and only a Cartesian one. is stored by value, for the same reason CartesianAOView stores its powers by value.

Template Parameters
SAOTypeA const-qualified SphericalAO. Only read-only views are supported for now: the polymorphic shell API is read-only, so a mutable view would have nothing to write through. The parameter is kept so that *this has the same shape as CartesianAOView, and so that a mutable view can be added without changing the spelling of the read-only one.

Creates the component m of the shell shell aliases, taking ownership of shell.

Identical to the ctor taking a view by reference, except that *this keeps shell rather than cloning it. This is what lets a pure shell, which builds a new view of its Cartesian shell for each AO it hands out, give that view to the AO without a second allocation.
