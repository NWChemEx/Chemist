Detailed Description

Types shared by both ChemistClassTraits<AtomicBasisSet> specializations.

An atomic basis set stores the parameters of its shells as one contracted Gaussian's worth of state per shell, so the parameter types are pulled out of ChemistClassTraits<ContractedGaussian> and the shell types out of ChemistClassTraits<AOShell>, rather than being redeclared here.
