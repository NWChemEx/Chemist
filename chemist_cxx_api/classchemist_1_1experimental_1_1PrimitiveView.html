Detailed Description

template<typename PrimitiveType>
class chemist::experimental::PrimitiveView< PrimitiveType >

An object which behaves like a Primitive, but aliases its state.

*this is the primitive-level counterpart of PointView, and exists for the same reason: to give a non-owning handle the exact same API as the owning class, without duplicating that API's declaration, documentation, or implementation. *this is what a future SoA-backed primitive set would hand out when indexed, and it is also useful on its own as a non-owning handle to a Primitive.

Template Parameters
PrimitiveTypeA, possibly const-qualified, Primitive. PrimitiveView<Primitive> aliases mutable state; PrimitiveView<const Primitive> aliases read-only state and has no setters at all.

Overwrites the state *this aliases with rhs's.

This is the copy assignment operator. Like the templated assignment above, and unlike the copy ctor, it is a deep assignment: it writes through to the aliased state rather than rebinding *this. This method only exists when *this aliases mutable state; instantiating it for a read-only view is a compilation error.
