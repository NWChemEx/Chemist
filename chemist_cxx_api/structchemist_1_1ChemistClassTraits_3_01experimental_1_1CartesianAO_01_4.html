Type acting like a mutable reference to the contracted Gaussian.

Note this is a ContractedGaussianView and not a ContractedGaussian&: a Cartesian AO which aliases its radial part needs to hand out something which aliases it too, and a C++ reference could not be rebound when the view is swapped.
