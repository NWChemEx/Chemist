Detailed Description

template<typename DerivedType, typename SAOType>
class chemist::experimental::SphericalAOCommon< DerivedType, SAOType >

Implements the API shared by SphericalAO and SphericalAOView.

Per docs/source/developer/design/basis_set/ao_hierarchy.rst, a spherical AO pairs a Cartesian shell with a component , and is the linear combination

of that shell's AOs, with the coefficients computed by detail_::spherical_transform_coefficient rather than stored. The sum runs over every AO in the shell, so the result does not depend on the order the shell enumerates them in, and *this accepts a shell of any ordering.

The coefficients carry (see docs/source/developer/design/basis_set/normalization.rst), i.e. they assume Cartesian AOs normalized only up to . chemist's Cartesian AOs apply themselves in normalized_evaluate, so *this combines their cg_normalized_evaluate instead, which stops at . evaluate needs no such care, since the Cartesian evaluate does not apply in the first place.

Exactly as with CartesianAOCommon, *this is a plain CRTP mixin, and it is the concrete classes which pick up AO or AOView.

Template Parameters
DerivedTypeThe class deriving from *this. Must define shell_(), returning a read-only reference to a Cartesian shell (an AOShell<CartesianAO> or an AOShellView<CartesianAO>), and m_(), and must declare *this a friend.
SAOTypeThe, possibly const-qualified, SphericalAO type the derived class models. This decides whether set_m exists.

Throws if shell and m can not make a spherical AO.

A spherical AO is a linear combination of Cartesian AOs, so the shell it is built on must be a Cartesian shell, and m must be valid for that shell's angular momentum. The former is part of shell's type, so it is checked at compile time; only the latter can fail at runtime. Public for the same reason as check_m.

inlinenoexcept

Determines if *this is value equal to rhs.

Two spherical AOs are value equal if they have the same component and their contracted Gaussians (which include the angular momentum) are value equal. The ordering of the Cartesian shells underneath is NOT considered, since the value of a spherical AO does not depend on it, and neither is whether either owns or aliases its shell.
