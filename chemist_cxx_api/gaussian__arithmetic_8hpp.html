Detailed Description

Implements the primitive normalization constant described in docs/source/developer/design/basis_set/normalization.rst. Declared here, rather than in float_arithmetic.hpp, because this is specific to the Gaussian primitive component and not something a bare coordinate would ever need.

Computes the primitive normalization constant, .

This is the factor which scales a single Gaussian primitive, paired with its Cartesian polynomial, to unit norm. It does not include the contracted-Gaussian factor or the Cartesian-AO factor ; those belong to the contraction and to the shell, respectively, and are not computable from a single primitive's parameters alone.
