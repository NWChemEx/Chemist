Detailed Description

template<typename DerivedType, typename ShellType>
class chemist::experimental::CCAShellCommon< DerivedType, ShellType >

Implements the API shared by CCAShell and CCAShellView.

A CCA shell is a shell whose AOs are enumerated in the Common Component Architecture ordering, which is what libint2 calls its standard ordering. Per docs/source/developer/design/basis_set/ao_hierarchy.rst:

  • a Cartesian CCA shell is generated by letting run from down to zero and, within each , letting run from down to zero, e.g. ;
  • a pure CCA shell runs from to .

All of a shell's state is its one contracted Gaussian — and the center included — whatever its purity. A pure shell is built on the Cartesian shell of that contracted Gaussian, which *this presents as a view (get_cartesian_shell) rather than storing, so there is still exactly one contracted Gaussian per shell. As a result *this needs only one hook from the derived class, for either purity.

Exactly like CartesianAOCommon, *this is a plain CRTP mixin and does not itself derive from AOShell or AOShellView; the concrete classes pick up one of those.

Template Parameters
DerivedTypeThe class deriving from *this. Must define contracted_gaussian_() and declare *this a friend.
ShellTypeThe, possibly const-qualified, CCAShell<AOType> the derived class models. Its AO type decides the purity, and its const-qualification whether the setters exist.

template<typename DerivedType , typename ShellType >
const const_ao_reference & chemist::experimental::CCAShellCommon< DerivedType, ShellType >::at ( size_type  i) const
inline

Returns the AO at offset i.

The result is a read-only view, owned by *this, which aliases the state of *this: a CartesianAOView whose contracted Gaussian is *this's for a Cartesian shell, and a SphericalAOView of get_cartesian_shell() for a pure one.

The views are built the first time *this is indexed and rebuilt whenever the angular momentum has changed since, including a change made through get_contracted_gaussian(). The returned reference is invalidated, much like a reference into a std::vector, by anything which changes the angular momentum of *this or rebinds its contracted Gaussian (assignment, swap, deserialization), and by the destruction of *this. See detail_::AOViewCache.

Determines if *this is value equal to rhs.

Two CCA shells are value equal if they have the same purity and their contracted Gaussians are value equal. The ordering is the type, so it can not differ. Whether either owns or aliases its contracted Gaussian is NOT considered.

Sets the total angular momentum of *this.

This writes into the contracted Gaussian, so it changes the number of AOs in *this and every view aliasing the same contracted Gaussian observes it. AO views previously obtained from *this keep their old angular indices, and so no longer agree with the contracted Gaussian they alias; re-index *this after calling this.

When *this models a read-only shell this method does not participate in overload resolution.
