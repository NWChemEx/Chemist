Detailed Description

Traits for a mutable experimental::Point.

The experimental point component deliberately keeps the concrete floating-point type out of its API. Coordinates are therefore modeled by the type-erased wtf::fp::Float class and handed out as wtf::fp::FloatView objects. Whether the resulting view is mutable or read-only is decided here, by which specialization of this struct is selected.
