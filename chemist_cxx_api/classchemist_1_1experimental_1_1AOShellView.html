Detailed Description

template<typename AOType>
class chemist::experimental::AOShellView< AOType >

Abstract base class of the aliasing shells of one purity.

*this is to AOShell<AOType> what AOShellBaseView is to AOShellBase: it answers the same questions, through the same AOShellCommon, but aliases the state rather than owning it. See AOShell for why the purity is a layer of its own. The members here are the ones whose result is typed by the owning/aliasing distinction.

Template Parameters
AOTypeThe kind of AO *this holds: CartesianAO or SphericalAO.
