Detailed Description

An ordered set of points in three-dimensional Cartesian space.

Points are almost never encountered alone. They are encountered in sets, and the layout of that set — not the layout of any individual point — is what determines whether downstream code can be vectorized or handed directly to an external library.

The PointSet class decouples the abstraction of "a set of points" from how that data is actually stored.

Note
The PointSet class currently stores the coordinates of the points in three separate arrays, one for each Cartesian direction. Additional layouts can be added by wrapping the state in a PIMPL. Doing so is left until another layout is actually needed.
