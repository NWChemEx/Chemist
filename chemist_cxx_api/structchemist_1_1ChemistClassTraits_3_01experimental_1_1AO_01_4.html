Detailed Description

Traits for experimental::AO.

Every AO, whatever its kind, is built on exactly one contracted Gaussian, so the types describing the angular momentum, the center, and the contracted Gaussian itself are pulled straight out of ChemistClassTraits<experimental::ContractedGaussian> rather than being redeclared here.

Unlike most traits there is no const specialization. The API an AO shares with an AOView (i.e., AOCommon) is entirely read-only, so the only reference types needed are the read-only ones, and those are the same regardless of the const-qualification of the AO.
