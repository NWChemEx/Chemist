Detailed Description

template<typename DerivedType>
class chemist::experimental::detail_::AOShellViewImpl< DerivedType >

Code factorization for implementing AOShellView's virtual methods.

*this is to AOShellView what AOViewImpl is to AOView. The derived class must:

  • define a copy ctor, which for a view is shallow,
  • be value comparable, and
  • define a shell_type alias naming the owning shell it materializes into, along with a private as_shell_value_() method returning one by value.
